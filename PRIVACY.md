# Privacy (template for hosted instances)

If you host CodeNaksha publicly, publish a privacy note like this one and adjust
it to match your setup.

- **What we receive:** the zip you upload, or the text you type in prompt mode.
- **What we keep:** uploaded files are deleted right after analysis. The
  analysis result is kept in memory for up to 60 minutes so your browser can
  load it, then discarded. Short AI-generated file summaries are cached by
  content hash to avoid recomputing them.
- **What we never do:** run your code, share it, or use it to train models
  (unless you explicitly opt in).
- **Where it runs:** on our own server with a locally hosted model. Nothing is
  sent to third-party AI services.
